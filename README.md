# FandomVerse

A cinematic fandom universe demo based on the supplied FandomVerse reference screenshots.

## Included interactions
- Seven moving portrait monoliths: Anime, Manga, Comics, K-Pop, Gaming, Movies, TV Shows
- Each monolith shows a category image, name, platform, and moves as one unit when the carousel is dragged or scrolled
- Monolith clicks work directly and trigger a glass-shatter transition into the selected universe
- Category pages include search, genre filters, and sorting (A–Z, Best ratings, Newest)
- Favourite hearts persist in localStorage
- Title detail pages include genres, description, favourites, and session-only notes
- More-from-this-universe cards appear before the footer
- Home page includes a spacious featured section with highly rated/newer picks before the footer
- Global search overlay removed; category search remains available where it is useful
- Footer keeps Universe links plus About Us and Contact Us
- About Us opens its own page with a project story panel
- Contact Us includes a username/comment form and an embedded Aptech Qatar map
- GitHub Pages workflow via GitHub Actions
