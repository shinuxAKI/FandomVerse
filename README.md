# FandomVerse

A cinematic fandom universe demo based on the supplied FandomVerse reference screenshots.

## Included interactions
- Seven moving category monoliths: Anime, Manga, Comics, K-Pop, Gaming, Movies, TV Shows
- Monoliths, their platforms, and labels move together as one unit
- Shatter transition when a universe is opened
- Category search, genre filters, and sorting (Top rated, Best ratings, Newest, A–Z)
- Favourite hearts persisted in localStorage
- Title detail pages with genres, description, and session-only notes
- More-from-this-universe cards before the footer
- Global search overlay and favourites page
- GitHub Pages workflow via GitHub Actions
